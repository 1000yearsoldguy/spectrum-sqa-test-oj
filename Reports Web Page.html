Critical security weaknesses identified that require immediate remediation.

Lack of Input Validation

The API does not properly validate submission size or content. This could be exploited for resource exhaustion (DoS) attacks or allow cross-site scripting (XSS) via malicious problem descriptions.

Insecure Authentication

The absence of rate limiting, account lockout policies, and password complexity rules makes the system vulnerable to automated brute-force attacks and credential stuffing.

Insufficient Session Management

No token blocklist is implemented. Stolen JWTs remain valid until expiry even after logout, posing a significant risk of unauthorized account access.

Weak Access Control

The principle of least privilege is not consistently applied. Several admin-only endpoints lack proper restrictions, and a "default to deny" policy is not enforced across the API.
